# 日语歌词振假名 · jp-furigana

为网易云音乐 PC 客户端的日语歌词添加振假名，支持 **网易云音译、离线词典、外部歌词网站，以及逐词人工纠音**。

1.6.3 整合外部网站、人工纠音、本地缓存管理与透明桌面注音，并修复请求与编辑冲突、缓存删除后不再获取、未知汉字吞掉已有读音等问题。插件沿用 [Leleawa/jp-furigana](https://github.com/Leleawa/jp-furigana) 的名称、标识和发布流程，RefinedNowPlayingNext 为可选适配。

## 新特性一览

| 功能 | 说明 |
| --- | --- |
| 外部网站注音 | 从 UtaTen 获取词级振假名，或从歌ネット获取罗马音并对齐；可自动选择或只使用其中一个网站 |
| 更灵活的歌曲匹配 | 清理 feat./cover/remix 等曲名附注，按歌手顺序查询；均未匹配时，再用歌名和多个歌词片段核对 |
| 通用异文对齐 | 结合整句与前后歌词确认对应关系，保留网易云原文，即使汉字、假名或字数不同也映射网站读音；不确定词边界时合并注音单元，人工纠音优先 |
| 手动指定歌词页 | 可为当前歌曲指定 UtaTen 链接，绕过自动搜索；选择保存在本曲 JSON 中，可随时清空恢复自动搜索 |
| 独立代理与重试 | 可为歌词网站单独配置代理；支持手动重新获取，以及可关闭的失败自动重试 |
| 播放页设置 | 适配 RefinedNowPlayingNext 3.0.2，在「歌词」后增加「注音」设置入口 |
| 人工纠音 | 在播放页逐词修改读音、保存和恢复；没有网站歌词的歌曲也可以编辑 |
| 本地歌词管理 | 每首歌一份 JSON，支持自定义目录、搜索、查看、空间统计、播放并编辑和删除 |
| 漏注音与排版修复 | 改善旧字体、部分未知汉字的注音，调整相邻汉字与长振假名的间距，减少重叠 |
| 透明桌面歌词 | 默认随原桌面歌词启停；复用当前读音和纠音，沿用原字体、颜色、字号及原生设置菜单，支持播放控制、时间微调和锁定穿透 |

## 安装与开始使用

### 环境

- Windows 版网易云音乐；基础网页注音保留原版 2.10.x / 3.x 的适配逻辑，新增透明桌面注音在 3.1.42 验证。
- BetterNCM **1.3.0 或更新版本**；建议使用 [1.3.4](https://github.com/std-microblock/chromatic/releases/tag/1.3.4)。
- 外部网站获取需要 Windows 自带的 PowerShell 5.1 和 `curl.exe`（Windows 10 1803 或更新版本）。
- 可选 **RefinedNowPlayingNext 3.0.2**，用于播放页「注音」设置与内联纠音；没有 RNP 时可使用 BetterNCM 插件设置及受支持的歌词页面。RNP 自身的客户端版本要求另计。

不同客户端版本和歌词插件的页面结构可能不同，具体测试范围见 [验证记录](docs/validation.md)。[透明桌面注音](docs/desktop-lyrics.md) 使用 Windows 自带的 .NET Framework 4.8/WPF 绘制；原生桌面歌词接口本身没有振假名输入能力。

### 安装

1. 在 BetterNCM 插件商店安装「日语歌词振假名」；手动安装可从 [Releases](https://github.com/Leleawa/jp-furigana/releases) 下载 `jp-furigana.plugin`。推送上游 `main` 后，CI 在检查通过且桌面组件从公开源码编译完成时创建 `v<版本>` Release；已有标签会跳过。
2. 退出网易云音乐，将插件包放入实际 BetterNCM 数据目录下的 `plugins/`。默认通常为 `C:\betterncm\plugins`，自定义安装请以实际目录为准。
3. 更新时把旧包备份到插件目录以外。若曾安装独立 Plus 版，先移出 Plus 包，再使用本版；每首歌的 JSON 缓存和人工修改可以继续沿用。已有原版设置优先，仅在没有原版设置时复制 Plus 偏好一次。
4. 启动网易云，进入「BetterNCM → 插件 → 日语歌词振假名」，将「读音来源」选为 **外部网站**。
5. 播放日语歌曲并打开歌词页。如已安装 RefinedNowPlayingNext 3.0.2，也可在播放页设置的「注音」中调整。

未切换来源时，仍按原来的网易云音译方式注音；选择词典来源则使用内置 kuromoji + IPADIC 推读音。

桌面注音默认开启，已保存的关闭选择会保留。**注音开关与网易云桌面歌词开关相互独立**：只开注音时等待，不打开桌面歌词或启动绘制组件；之后打开原桌面歌词即显示注音。只开原桌面歌词则保持原样。关闭桌面注音后恢复原窗口，并隐藏「沿用原桌面歌词样式」等选项；关闭原桌面歌词会停止绘制，但保留注音偏好，方便下次打开。

自行打包需安装 Node.js，在仓库目录运行：

```sh
node tools/pack.js
```

产物为 `builds/jp-furigana.plugin`，按上述步骤安装即可。

## 外部网站注音

功能只对确认含日语原歌词的歌曲生效。优先检查当前歌曲 ID 对应的完整网易云 LRC / YRC 原文，也可复用客户端已加载的同曲原歌词；日文制作人员姓名、翻译、罗马音、歌名、歌手及上一首残留歌词均不作为触发依据。没有日语内容时，不搜索网站、不刷新网站缓存、不套用人工指定页，也不替代原桌面歌词；原有桌面歌词开关和注音偏好保留。

英日混合歌曲正常支持，不会因为开头是英语就跳过。无法确认原歌词时先等待，失败则显示原因；此时「重新获取当前歌曲」只重新检查网易云原歌词，确认含日语后才允许外部获取。判断复用现有的网易云歌词请求，不为每首歌额外请求百科接口，也不新增语言数据库。

| 网站 | 读音来源 | 使用方式 |
| --- | --- | --- |
| [UtaTen](https://utaten.com/) | 网页上的词级振假名 | 自动模式优先使用，也可单独选择 |
| [歌ネット / Uta-Net](https://www.uta-net.com/) | 日文歌词与独立罗马音 | 通过原插件算法对齐到汉字，自动模式下作为备用 |

播放歌曲时先读取本地缓存。没有可用网站缓存时，先显示网易云音译或离线词典注音，同时查询所选网站；仅保存人工纠音的文件不会阻止这次获取。获取成功后，只替换能够与原歌词匹配的读音，**保留原歌词文字、翻译和时间轴**。

搜索先清理曲名末尾的 feat./cover/翻唱/remix 等附注，再按网易云的歌手顺序逐一尝试。例如《花 feat. 花譜》、歌手 Guiano / 花譜，会依次查询「花 + Guiano」「花 + 花譜」；均未匹配时，才仅搜「花」，用多个歌词片段核对同名候选。无法唯一确定歌曲时继续使用本地注音。整套搜索与歌词核对流程算一次尝试，不增加重试额度。

### 手动指定歌词页

在 BetterNCM 设置或 RNP →「注音」点击 **「手动指定歌词页」**，输入 `https://utaten.com/lyric/…/` 并确认。插件会直接读取该页，跳过歌名、歌手的自动搜索校验；仍只将能够对应到当前歌词的注音用于显示。

指定链接记录在同一首歌曲 JSON 的 `manualSource` 项中，获取失败后仍保留，重新获取也继续使用；原网站字段和 `userEdits` 人工纠音保留。再次打开输入框，**留空并确认**即可恢复自动搜索。此入口适用于「自动」或「仅查询 UtaTen」，仅使用歌ネット时不启用。

**「仅查询 UtaTen」限制的是网站来源。** 它不会请求或使用歌ネット的缓存，但加载期间、未匹配的歌词行仍会使用网易云音译或词典回退。因此，显示“已获取 UtaTen”不代表整首歌的每个词都来自 UtaTen。可通过「查看来源网页」检查网站原文。

### 代理与重新获取

在原插件设置页启用代理并填写地址，例如 `http://127.0.0.1:7890` 或 `socks5h://127.0.0.1:1080`。支持 HTTP、HTTPS、SOCKS5、SOCKS5H；需要已有的代理服务，不支持在地址中填写账号密码。

代理 **仅用于访问歌词网站**，不改变网易云播放、歌曲信息或官方音译请求的网络设置。

- **重新获取当前歌曲**：重新搜索和下载；获取期间及失败后继续显示已有缓存，保留已有人工修改。
- **失败后自动重试**：对超时、连接中断、HTTP 200 空页面等临时故障最多补试三次，换歌或关闭功能时取消旧任务。自动模式先尝试另一个网站，再等待重试；不会重复请求已明确拒绝访问或未匹配的来源。
- **关闭自动重新获取**：仍保留首次获取，只关闭后续自动补试。搜索无结果、版本有歧义等情况不会无限重试。

BetterNCM 插件设置页和 RefinedNowPlayingNext 的「注音」页都会显示获取进度、失败的网站及原因（如搜索页面为空、`curl error 28` 超时、DNS / 代理连接失败、HTTP 状态或歌词不匹配），等待自动重试时也保留原因。**1.5.3 修复了 UtaTen 请求缺少来源页请求头造成的 HTTP 200 空页面**，升级后可点击「重新获取当前歌曲」。HTTP 200 空页面不表示网站没有收录歌曲；若仍发生，设置中会保留错误原因。「仅查询 UtaTen」仍严格限制来源，不会自行切换网站。

## 在播放页人工纠音

即使网站有注音，也可能与歌手实际唱法不同，例如歌词写作「戀人」，实际唱作「あなた」。可以在播放页直接修正这些位置：

1. 点击 **「进入编辑模式」**。
2. 鼠标悬浮到独立注音单元，点击输入框，输入对应假名。
3. 按 **Enter** 或点击 **「应用」** 保存；也可取消，或恢复该词的原注音。
4. 完成后退出编辑模式，正常播放时只显示修改后的注音。

**编辑模式下，所有原注音保持原来的位置；修改处原注音原地划掉，新注音显示在它的上方。** 未保存的输入会有提示；保存失败保留输入，换歌后不会把上一首的修改误写入新歌。

**没有网站歌词也能编辑。** 如果没有网站注音记录，进入编辑前先尝试获取；失败后以网易云音译或词典分词创建本地 JSON，只保存人工修改。没有读音的可编辑汉字单元以「＋」提示。

网站请求进行中，第一次点击编辑按钮只把文字变成红色「将中断网站注音获取，再次点击进入编辑模式」；第二次点击才停止本轮请求并进入编辑。请求完成、换歌或开始新请求后会清除确认。主动中断只影响本轮；下次播放或手动重新获取仍可请求，人工修改会保留。

人工修改优先加载，可单处恢复，也可在管理页恢复整首歌。若重新获取后原文、分词或原读音发生变化，无法匹配的修改仍保留在文件中，但不会强行套用到其他位置。

## 本地歌词缓存与管理

默认存储位置：

```text
<BetterNCM 数据目录>/lyrics/jp-furigana/<网易云歌曲 ID>.json
```

默认目录和歌曲 JSON 结构继续沿用，网站数据与 `userEdits` 是独立部分。可在设置页自定义完整磁盘路径。缓存不放在插件解压目录内，更新插件时可继续复用；更改目录不会自动搬迁原有文件。

**每首歌始终只有一份歌曲 JSON。** 网站原文与读音保留在原字段中，人工修改额外记录在 `userEdits` 内，不另存一份完整歌词。重新获取网站歌词时也保留人工修改。

打开 **「本地歌词管理」** 可以：

- 查看缓存歌曲数量、空间占用和每首歌的修改数量。
- 按歌名、歌手或歌曲 ID 搜索，或只显示已修改的歌曲。
- 查看原歌词及修改前后的读音，恢复整曲原始读音。
- 点击「播放并编辑」，切换到对应歌曲后进入编辑模式。
- 删除单曲缓存及其人工修改；删除前会确认。

![本地歌词管理](https://github.com/user-attachments/assets/b380a6c5-60d6-4fdf-b93b-64f96619361e)

有效的网站缓存命中后不重复请求歌词网站。仅有人工修改、没有网站数据的本地文件不算网站缓存，下次播放仍会尝试获取；成功后在同一文件中合并网站数据并保留修改。保存采用临时文件校验与原子替换，降低写入失败导致原文件损坏的风险。

功能不依赖数据库服务。网络与保存组件按需运行并退出；可选桌面绘制组件只在启用桌面注音且桌面歌词可见时运行，停用后退出。原插件自带的离线词典仍会占用内存，实际开销取决于客户端和歌词页面。

MIT 等代码许可不涵盖网站歌词。歌ネット的[使用条款](https://www.uta-net.com/info/kiyaku.html)限制未经许可的抓取等使用；UtaTen 的[使用条款](https://utaten.com/index/agreement)对个人非营利浏览以外的复制、转载、修改等要求事先书面许可。目前未取得针对本插件的个别书面数据授权，外部自动获取与本地缓存的条款适用仍需另行确认。外部来源默认不启用，发布包不包含实际歌词缓存。完整网络行为、许可和商店审核说明见 [构建与分发](docs/distribution.md)。

## 注音修复与已知限制

插件在查词和对齐时兼容部分新旧字形，例如 `會/会`、`戀/恋`、`凜/凛`、`墮/堕`，显示时保留原字。修复 `出會った` 等漏注音情况，为 `堕とす / 堕ちる` 补充语境读音，并在罗马音对齐无歧义时补全部分未知汉字。相邻长注音会预留间距，兼顾原生 ruby 和旧内核的降级排版。

使用时还需注意：

- 网站收录和词典都不保证符合每一次演唱；网站没有歌曲、歌词差异过大或同名版本无法区分时，仍会回退。
- **相同整句在重复演唱中共用人工修改**，目前不按时间戳区分同一句的不同唱法。
- 人工编辑以现有分词单元为单位，不提供任意重分词或歌词原文编辑。
- 删除缓存会同时删除该曲人工修改；建议在批量清理或迁移目录前备份 JSON。
- 桌面注音目前适配横排；竖排继续显示原桌面歌词。其他歌词插件或未来 RNP 版本的布局变化可能需要继续适配。

完整获取策略、缓存结构与使用说明见 [外部歌词与人工纠音说明](docs/external-lyrics.md)，测试覆盖和未验证范围见 [验证记录](docs/validation.md)。
