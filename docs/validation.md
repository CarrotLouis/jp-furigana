## 真实网站和代理

使用与插件相同的 PowerShell + Windows curl 传输脚本，按歌名与歌手从搜索页开始抓取；未使用预先硬编码的歌词地址完成搜索。

| 歌曲 | UtaTen 搜索＋获取 | 歌ネット搜索＋获取 |
| --- | ---: | ---: |
| 恋人を射ち堕とした日 / Sound Horizon | 3.385–4.105 秒 | 3.948–4.640 秒 |
| know me... / 八木海莉 | 2.906–2.944 秒 | 3.650–4.030 秒 |

以上为两轮本机测试的耗时，不是稳定网络性能保证；初次测试还遇到过一次请求超时。普通 Python 请求歌ネット曾返回 403，实际采用的 Windows curl 路径成功返回并解析两个网站。

缓存读取为 1–3 毫秒，网站请求数为 0。时间不包括网易云首次加载词典，也不能代表真实客户端渲染延迟。

使用临时回环 HTTP CONNECT 代理完成一次 UtaTen 请求，确认流量确实经过配置的代理；代理随后关闭。SOCKS5 / HTTPS 选项由系统 curl 提供，本次未用真实 SOCKS5 / HTTPS 代理服务测通。

UtaTen 的真实页面已验证可将用户提供的旧字体歌词中的 `戀人` 对应到 `あなた`。不在仓库中发布完整真实歌词、下载页面或代理本地配置。

## 尚未验证的范围

本次已备份并替换本机 BetterNCM 的插件包，安装文件哈希与测试产物一致；未重启网易云。因此以上网页 DOM 集成验证是模拟客户端环境，不能当作本机网易云 3.1.41 的最终实机验收。正常重启后应检查实际歌词容器、BetterNCM 文件读写以及系统是否允许按需启动网络脚本。原生桌面歌词不在支持范围。

原词典仍由上游 kuromoji 加载；本次未测量真实网易云进程的内存 / CPU 增量，不宣称固定占用值。
