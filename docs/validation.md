# 验证记录

## 本次上游 PR 范围

本分支只包含网页歌词注音、外部网站、人工纠音、本地管理和可选 RNP 适配。透明桌面绘制、二进制、内部窗口调用及其编译和测试从本 PR 移除，由独立 Plus 版继续维护。

以下 DOM 测试使用模拟的网易云与 RNP 页面，不代表所有客户端版本的实机验收。测试资料以人工短句及最小复现片段为主，不随仓库提交真实网页、整首歌词、用户缓存和代理配置。

## 维护者审阅问题与回归

- 保留原插件名称、slug、作者及原仓库链接；RNP 恢复可选适配。已有原版设置优先，仅缺失时复制 Plus 偏好，不修改 Plus 的设置和计算缓存；不带入桌面设置。
- 进行中请求的第一次编辑点击只显示红色确认文字「将中断网站注音获取，再次点击进入编辑模式」，第二次才取消同一轮请求。请求完成、换歌或重新获取后清除确认；迟到响应不覆盖文件。`ensureLocal` 拒绝隐式取消。
- 只含 `userEdits` 的文件不视为网站缓存；没有网站记录时，主动进入编辑先尝试获取，用户可确认中断后进行本地编辑。后续播放仍允许获取，且保留修改。
- 缓存管理「播放并编辑」只为本轮读取指定来源，不修改全局 `externalProvider`。成功删除当前缓存后清除加载标记并重新获取；删除失败保留当前数据和状态。
- 未知汉字合并槽保留原有词典片段；促音严格规则只用于未知槽相邻锚点。合成复现、旧字体、未知汉字、实际词典和罗马音对齐均有回归。
- 间距处理先检查缓存和宿主连接状态，字体变化按有限频率探测；DOM 重建、设置和字体变化使缓存失效。两处滑块只在 `change` 持久化，`input` 仅预览数值，菜单刷新不覆盖待提交值。
- CI 保留上游 main 自动发布及已有标签跳过，仅在 Linux 检查和 Windows 文件保存测试通过后发布；fork 和 PR 只检查并提供 artifact。

## 新增网页功能的覆盖

- UtaTen 搜索空页面：相同搜索参数及网络下，默认 curl 曾返回 HTTP 200、正文 0 字节；补充固定站内 Referer 后返回候选列表，仅改 User-Agent 无效。错误状态区分超时、HTTP 错误、空正文和没有匹配，并同步显示在两处设置。
- 搜索顺序：曲名清理 feat./cover/翻唱/remix 附注；按首位、后续歌手依次尝试，之后才按歌名查询并用多个歌词片段核对。整个流程共用一次尝试和重试额度。
- 手动来源：UtaTen HTTPS 地址校验、绕过搜索、单份 JSON 保存、失败后保留选择、刷新保留纠音、清空恢复自动搜索、来源范围隔离及换歌后迟到响应处理。
- 日语判断：只使用同曲 ID 的 LRC / YRC 原文；排除制作信息、翻译、罗马音、歌名、歌手与旧曲内容。覆盖纯英文、英日混合、等待或失败、仅 YRC、客户端原文不完整及关闭制作信息跳过选项的场景。
- 将所需的客户端原歌词筛选及 YRC 纯文本解析放入文本核心，验证毫秒时间轴、原文排序、无效输入、旧歌曲拒绝和不混入翻译；没有桌面模块依赖。
- 通用异文对齐：结合前后锚点确认对应句，保留网易云文字并投影网站读音。字符或字数不同仍可处理；边界不确定时合并注音单元，整段采用网站读音。覆盖 180 组确定性字符编辑、Unicode、重复句歧义、短句上下文、另一段精确文本排除、Uta-Net 罗马音、人工修改优先和旧缓存保存。
- 编辑浮窗：在整块歌词及注音上方定位；上方放不下时移到下方，限制视口溢出，输入框扩展后重新定位，避免遮住当前歌词。
- 人工纠音：单处／全曲恢复、来源隔离、无网站记录创建、保存失败保留输入、并发与过期保存拒绝、IME Enter、换歌防误存和未保存提示。

## 检查入口

- `npm test`：文本核心、网站解析与匹配、原子保存协议、来源与语言判断、手动来源、纠音、编辑、缓存、设置迁移及原生网页／RNP DOM 集成。
- `node tools/test-rnp-dom.js` 及 `slide`、`float noruby`、`slide noruby`、`lyricbar`、`lyricbar noruby`：六种网页逐字／无 ruby 兼容场景。
- `node tests/cache-write.test.cjs`：Windows 真实文件原子替换、并发变化拒绝、无效 JSON 拒绝及临时文件清理；只操作测试目录。
- `npm run check:store` 与 `node tools/pack.js`：标识、版本、文档链接、许可副本、预览体积和 28 项包内文件；无桌面脚本、可执行组件或相关 manifest 注入。

## 已有公开网站实测的边界

曾使用实际 Windows PowerShell / curl，从搜索到解析与缓存验证《恋人を射ち堕とした日》《know me...》《残酷な天使のテーゼ》《花 feat. 花譜》，均成功；《花 feat. 花譜》使用清理后的「花 + Guiano」。另有歌手别名触发仅歌名及歌词片段核对的验证。缓存重读不发起网站请求。这是特定时间与网络的验证，不代表长期成功率或固定延迟，本轮未重复代理测试。

语种研究中，《Sunshine Girl》（28593339）的百科标注为日语、英语，《Drown》（1401456829）为日语，两者实际原歌词均含假名；《Attention》（473817398）的原歌词无假名，判为跳过。运行时复用现有原歌词，不逐曲额外查询百科。

本轮不替用户安装、重启或改变正在运行的网易云。上游 PR 的整理与 Plus 的正式发布分开进行，维护者回复保留草稿，待用户确认后发送。
