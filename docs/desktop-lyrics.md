# 透明桌面注音（1.6.0）

在 BetterNCM 的插件设置或 RefinedNowPlayingNext →「注音」中控制「启用注音桌面歌词」。默认开启，保留已经保存的关闭选择；原桌面歌词关闭时不运行绘制组件。网页与桌面共用读音来源、假名类型、注音大小、不透明度以及已保存的人工纠音，不再下载或保存第二份歌词。

两个开关相互独立。1.6.1 起，切换「启用注音桌面歌词」不会更改网易云的桌面歌词开关：先开注音、后开桌面歌词，或先开桌面歌词、后开注音，都会在两者均开启时接管。只开注音时不显示任何歌词窗口，也不启动绘制组件；只开原桌面歌词时保持原生显示。关闭原桌面歌词会停止绘制，保留注音偏好；关闭注音则在原桌面歌词仍开启时恢复原生显示。

1.6.2 起还需确认当前歌曲原歌词含日语。纯英文等歌曲继续使用原生桌面歌词，不因制作信息里的日文姓名启动外部搜索或绘制组件；从日语歌切换到非日语歌时恢复原窗口，保留注音偏好。英日混合歌曲正常启用，判断不取决于当前显示的那一句是否为日语。

原网易云桌面歌词开关、托盘菜单和快捷键继续控制显示。替代窗口启动成功后隐藏原窗口；停用桌面注音或全局注音时恢复原窗口。关闭桌面歌词后不保留绘制进程，再打开时自动启动。

## 外观与交互

- 默认沿用原桌面歌词的字体、粗细、字号、渐变颜色、描边、对齐、置顶、翻译和单双行设置。原文与翻译使用相同字号；描边先画在字形外，再填充文字。字体由同一系统字体绘制，WPF 与原生窗口的字距和抗锯齿可能略有不同。
- 小假名位于对应原文上方，宽度按底字和假名中较宽者安排，长注音为邻词留出间隔。每行都保留固定注音高度，没有注音时原文基线保持不变；开启翻译或罗马音后，即使某行缺少附加文本也保留其空位。原文和附加行按可见字形边界对齐，忽略首尾空白造成的视觉偏移。
- 背景为逐像素透明，无网页黑底或色键边缘。未锁定时鼠标移入歌词后显示整个窗口的半透明底板、边界和图标工具栏，移出后延迟 2 秒隐藏；返回时取消隐藏，拖动或缩放过程中持续显示范围，直到操作结束。拖动歌词可移动窗口，边缘可以调整大小，宽度及位置保存在本地设置。
- 工具栏依次提供打开当前歌曲、+0.5 秒、-0.5 秒、上一首、播放/暂停、下一首、设置、锁定与关闭。播放和时间调整调用网易云原来的动作，不自行控制音频。
- 齿轮直接调用网易云原有独立菜单，保留置顶、单双行、翻译/罗马音、排版、配色、报错和「更多设置」。选择普通选项时保持播放页面；只有点击原生「更多设置」时才退出 RNP 遮罩、显示网易云设置页。
- 菜单中的「不显示」「翻译」「罗马音」决定原文下方的附加行；优先使用客户端当前时间轴，YRC-only 歌曲也可从对应翻译和罗马音条目对齐。
- Ctrl + 滚轮调整字号；普通滚轮微调时间。沿用样式时字号同时写回原生绘制接口。锁定后歌词让鼠标穿透；将指针移到歌词区域，歌词上方居中显示透明白色开锁图标，不覆盖注音或原文。BetterNCM 插件设置页另保留解锁入口。缩窄窗口时工具栏自动换行。
- 注音大小、不透明度、假名类型、读音来源、跳过规则和人工纠音与播放页共用设置。「逐字歌词模式」打开且存在文字相符的 YRC 时间轴时，按词开始时间切换已唱颜色；关闭或缺少匹配时间轴时保持整行显示，不推测时间。词间切换复用读音，不重复分词。
- 可取消「沿用原桌面歌词样式」，单独调整桌面字号、置顶和翻译显示。关闭桌面注音后，这些样式选项隐藏。

目前适配横排布局。选择原桌面歌词的竖排模式时，自动保留原窗口；切回横排后恢复桌面注音。菜单直接使用原生控件；工具栏使用本插件自绘的通用矢量图标，没有打包网易云专有皮肤或图标字体。目前未完成所有缩放比例的像素对照，不声明整套界面逐像素相同。客户端原生动作接口发生变化时会显示失败原因并回退。

## 运行与资源

原生桌面歌词接收 LRC/YRC 原文、翻译和罗马音字符串，没有词级振假名输入。客户端普通网页浮窗在本机验证中不能提供透明背景，因此使用单独的 WPF 绘制窗口。

绘制组件 `desktop-host.exe` 约 55 KiB，使用 Windows 自带的 .NET Framework 4.8，不捆绑 WebView、词典或播放器。关闭功能和桌面歌词时进程退出。只在歌词行、词级高亮或设置变化时重绘，采用软件绘制以避免单独的 D3D 上下文。

本机模拟 IPC 测试启动约 0.32 秒，活动窗口工作集约 59 MiB、私有提交约 58 MiB，3 秒空闲采样新增 CPU 时间为 0。锁定时每 120 毫秒检查一次鼠标位置，用于显示解锁图标；其他情况下不运行该计时器。数值只代表该次测试，不是所有机器的固定占用。

进程只监听本机回环地址，连接使用每次随机生成的密钥。运行目录 `<BetterNCM 数据目录>/lyrics/jp-furigana/desktop/` 只临时记录连接信息，不保存歌词正文；退出时移除。主插件断开超过 15 秒时组件自动退出。

## 构建与验证

源代码位于 `native/DesktopLyricsHost.cs`，使用本工程 MIT 许可。正式包的组件由 CI 的 Windows 作业从源码编译，Linux 回归和 Windows 自测均通过后，上游 `main` 的推送才会创建 Release；构建输入、工作流地址和包哈希记录在随构建产物提供的 `native-build-info.json`。Windows 下也可用系统 .NET Framework 编译器重新构建并执行透明像素、锁定穿透、解锁回归：

```powershell
powershell.exe -NoProfile -File tools/build-desktop-host.ps1 -Check
node tests/desktop-native.test.cjs
npm test
node tools/pack.js
```

普通离线测试覆盖时间单位、偏移、翻译匹配、与网页共用的纠音、换歌和跳转、旧任务取消、原窗口恢复，以及原桌面歌词关闭后重新打开。Windows 测试使用模拟歌词、自己的测试窗口和回环连接，不操作网易云或 Anki。
