# 透明桌面注音（1.6.0 实验）

在 BetterNCM 的 Plus 设置或 RefinedNowPlayingNext →「注音」中打开「启用注音桌面歌词」。默认关闭。网页与桌面共用读音来源、假名类型、注音大小、不透明度以及已保存的人工纠音，不再下载或保存第二份歌词。

原网易云桌面歌词开关、托盘菜单和快捷键继续控制显示。替代窗口启动成功后隐藏原窗口；停用桌面注音或全局注音时恢复原窗口。关闭桌面歌词后不保留绘制进程，再打开时自动启动。

## 外观与交互

- 默认沿用原桌面歌词的字体、粗细、字号、渐变颜色、描边、对齐、置顶、翻译和单双行设置。原文与翻译使用相同字号；描边先画在字形外，再填充文字。字体由同一系统字体绘制，WPF 与原生窗口的字距和抗锯齿可能略有不同。
- 小假名位于对应原文上方，宽度按底字和假名中较宽者安排，长注音为邻词留出间隔。中文翻译在原文下方，不加注音。
- 背景为逐像素透明，无网页黑底或色键边缘。鼠标移入歌词后显示工具栏，拖动歌词可移动窗口，窗口宽度及位置保存在本地设置。
- 工具栏提供翻译切换、±0.5 秒、上一首、播放/暂停、下一首、原桌面歌词设置、锁定与关闭。播放和时间调整调用网易云原来的动作，不自行控制音频。设置按钮会退出 RNP 播放页并打开网易云的「桌面歌词」完整设置页。
- Ctrl + 滚轮调整字号；普通滚轮微调时间。锁定后歌词让鼠标穿透；将指针移到歌词区域，右上角会出现「解锁」按钮。也可在插件设置或 RNP「注音」内解锁。缩窄窗口时工具栏自动换行。
- 可取消「沿用原桌面歌词样式」，单独调整桌面字号、置顶和翻译显示。

目前适配横排布局。选择原桌面歌词的竖排模式时，自动保留原窗口；切回横排后恢复桌面注音。尚未声明跨网易云版本完全兼容，客户端原生动作接口发生变化时会显示失败原因并回退。

## 运行与资源

原生桌面歌词接收 LRC/YRC 原文、翻译和罗马音字符串，没有词级振假名输入。客户端普通网页浮窗在本机验证中不能提供透明背景，因此实验版使用单独的 WPF 绘制窗口。

绘制组件 `desktop-host.exe` 不到 40 KiB，使用 Windows 自带的 .NET Framework 4.8，不捆绑 WebView、词典或播放器。关闭功能和桌面歌词时进程退出。只在歌词行或设置变化时重绘，采用软件绘制以避免单独的 D3D 上下文。

本机模拟 IPC 测试启动约 0.34 秒，活动窗口工作集约 59 MiB、私有提交约 58 MiB，3 秒空闲采样新增 CPU 时间为 0。锁定时每 120 毫秒检查一次鼠标位置，用于显示解锁按钮；其他情况下不运行该计时器。数值只代表该次测试，不是所有机器的固定占用。

进程只监听本机回环地址，连接使用每次随机生成的密钥。运行目录 `<BetterNCM 数据目录>/lyrics/jp-furigana/desktop/` 只临时记录连接信息，不保存歌词正文；退出时移除。主插件断开超过 15 秒时组件自动退出。

## 构建与验证

源代码位于 `native/DesktopLyricsHost.cs`，使用本工程 MIT 许可。Windows 下可用系统 .NET Framework 编译器重新构建并执行透明像素、锁定穿透、解锁回归：

```powershell
powershell.exe -NoProfile -File tools/build-desktop-host.ps1 -Check
node tests/desktop-native.test.cjs
npm test
node tools/pack.js
```

普通离线测试覆盖时间单位、偏移、翻译匹配、与网页共用的纠音、换歌和跳转、旧任务取消、原窗口恢复，以及原桌面歌词关闭后重新打开。Windows 测试使用模拟歌词、自己的测试窗口和回环连接，不操作网易云或 Anki。
